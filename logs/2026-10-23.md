## [08:54] 多轮会话 | transcript 持久化 + --continue/--resume + REPL

从单轮对话升级为多轮会话，支持跨进程记忆恢复与交互式 REPL。

### 修改

1. `src/mycode/agent/transcript.py`：
   - `__init__` 加 `session_id` 参数（恢复时复用已有 session 文件）
   - 加 `load(file_path)` 静态方法：读 JSONL → Anthropic messages 格式
   - 加 `latest_session_id()`：找最近 session（排除当前空文件）
2. `src/mycode/agent/loop.py`：
   - 拆出 `run_one_turn(ctx, prompt)`：REPL/会话恢复复用同一 Context
   - `run()` 改为创建新 Context 后委托 run_one_turn
3. `src/mycode/cli/main.py`：
   - 加 `--continue`/`--resume SESSION_ID` 参数
   - 无 prompt 时进入 REPL 交互模式（`>>>` 提示符、`/exit`/Ctrl+D 退出）
   - 会话恢复：加载历史消息灌入 Context + 复用已有 session 继续写

### Bug 修复

`latest_session_id()` 误取刚创建的空文件（Transcript 构造函数立即创建文件，mtime 最新）→ 排除当前 session_id + 恢复时清理空文件

### 验证

- 单轮不变 ✅
- --continue 恢复 ✅（用户实测：第 2 步回忆起"张三"）
- REPL 多轮 ✅（用户实测：第 2 轮回忆起第 1 轮内容）
