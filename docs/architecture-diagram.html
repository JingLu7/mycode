七、评测对比结果（12 任务 × 3 难度）

指标 mycode (qwen3-32b) claude-code (opus-5-5)
通过率 11/12 (91.7%) 11/12 (91.7%)
平均耗时 11.2s（快 5.4×） 60.2s
Easy (4 题) 4/4 ✓ 4/4 ✓
Medium (4 题) 4/4 ✓ 3/4（m3 超时 120s）
Hard (4 题) 3/4（h1 多文件分析失败） 4/4 ✓
效率归因 system prompt 更短 + 工具按需注册 + loop 轮数更少 重量级 harness + 完整 system prompt + 更多轮次
失败模式 多文件分析类（system prompt 不够全面） 简单 shell 任务超时（"杀鸡用牛刀"）
关键发现：两个 harness 通过率持平但失败模式互补——mycode 轻量 harness 在简单任务上效率优势明显（5.4×），claude-code 重量级 harness 在复杂分析任务上更全面。后续改进方向：mycode 补强多文件分析类 system prompt + Pass^k 稳定性验证。
